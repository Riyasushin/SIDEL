# Archive

This directory preserves superseded designs, dated runbooks, early verification notes, and point-in-time experiment reports.

Archived documents are useful for understanding how SIDEL evolved, but they are not current execution instructions. In particular, older files may refer to retired script stacks, prompt-controlled experiments, legacy artifact names, or incomplete reviewer semantics.

Use these sources for current work:

1. root `README.md`
2. `docs/architecture.md`
3. `docs/project-guide.md`
4. `docs/router-guide.md`
5. `docs/manager-guide.md`

The archive includes:

- early Codex/Claude router verification and attack reports
- legacy SWE-bench result summaries
- the completed shared-router refactor design and handoff
- dated step-zero/step-three analyses
- historical Claude auto-review and `tmux` runbooks
- background research and source-reading notes

When an archived statement conflicts with current code or documentation, treat it as historical context rather than a maintained contract.
